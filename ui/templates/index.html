Two-party extraction with a neighbor

The production mode: this node holds only its own TimeTagger's recordings and announces their timing, bases and multi-photon flags, never a bit. The neighbor finds its own recording of the same start time, aligns, matches and decodes, and both nodes store the same key under the same key_IDs in their pools for this link. Start it from the side whose detectors click less; requests from neighbors run by themselves and appear in the history below. Uses the error correction (5G NR LDPC or polar) and the options above.

Continuous QKD

Records without end in segments; each segment is aligned and sifted as it lands, its raw arrays replaced by about 1 MB of events, and every block of data goes through optimized Cascade (or 5G NR LDPC), verification and finite-key privacy amplification into the chosen link's KMS pool while the next block fills. Blocks of 5 minutes reach about 70% of the key rate of hour-long blocks; a block of seconds certifies nothing.

Two-party, production Idle

Each node records its own TimeTagger without end, in segments that start on the same UTC seconds at both sites (keep the clocks on NTP). Every block, the node announces its block's timing to each neighbor ticked below, which answers by itself with its own recording; both run optimized Cascade and both link pools receive the same keys, which the key management system relays to farther nodes. Tick a neighbor on the side whose detectors click less, and start the recording on both nodes. The settings are kept: after a restart the node resumes by itself.

Pipeline simulator

Simulated click streams through cmd/qkd_post_processing. Its keys are demo keys, replaced on every run and never handed to the KMS.

Run simulation

Brassard-Salvail Cascade as optimized by Martinez-Mateo et al. (2015): blocks from the QBER growing x4, no parity disclosed twice, halves inferred, corrections cascading back; f about 1.03-1.07.

3GPP TS 38.212 base graph 1 (py3gpp), exact belief propagation (ldpc library); the rate adapts by revealing punctured positions while a frame fails.
